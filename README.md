## Como executar
```bash
python -m venv .venv
.venv\Scripts\activate            # Windows (Linux/macOS: source .venv/bin/activate)
pip install -r requirements.txt
uvicorn server:app --reload
```
Abra http://localhost:8000 (duas ou mais abas para testar).
